# ADP-01 implementation gaps (Arcadestr client)

**Status:** tracked. Close an item only when code changes **and** a targeted test
passes. Consolidating or synchronizing `ADP-01.md` resolves nothing here.

This record compares the Arcadestr client with the consolidated ADP-01 (`0.3.0`).
Server-side gaps are tracked in `../adp-server/docs/protocol-implementation-gaps.md`.

None. Every tracked client gap is closed below.

## Verified conformant (no change needed)

- **Terminal states:** campaign chains skip successors once cancelled (`core/src/campaign.rs`). Grant chains admit only `granted → revoked` (`core/src/entitlements.rs`).
- **`503` handling:** `/game`, `/entitlement/claim`, and `/purchase/confirm` map `503` to the typed `AuthorizationUnavailable` error (`core/src/adp_client.rs`), not to a definitive failure.

## Test-run notes

- **Pre-existing failure:** `core/tests/publisher_projection.rs::additive_projection_migration_preserves_existing_rows_and_allows_verified_refresh` fails on `f359925`, before any of this work (`core/tests/publisher_projection.rs:224`). It concerns migration 25 and the marketplace cache, not ADP conformance, and is left unchanged.
- **Always run core tests with `--no-fail-fast`.** Without it, cargo stops at the failing `publisher_projection` binary and silently skips every later integration binary. This hid a regression from `c2c449d` in `core/tests/receipt_protocol.rs`, fixed in `6ddc8ed`.
- **Intermittent, unrelated:** `desktop` `install_game_tests::gate5_restart_rolls_back_candidate_and_serializes_recovery` failed once under load (a lifecycle lock held by a concurrent test) and passed in 6 isolated and 3 further full runs. `core` `credential_store::tests::dismissed_and_locked_suppress_until_interactive_retry` failed once and passed on rerun. Neither was investigated.
